# 同義の基準
同義とは「同じ組織・製品・イベントを、表記だけ変えて書いたもの」に限ります。
- 出す例：グーグル と Google（同じ会社のカタカナ表記と英字表記）

次のようなものは同義ではありません。出さないでください。
- ChatGPT と OpenAI：製品と、それを作った会社は別のもの
- 日本マイクロソフト と マイクロソフト：日本法人と本社は別の組織
- AIアシスタント と AIエージェント：似た概念でも別の言葉
- 上位・下位の関係（例：AI と 生成AI）、同じ分野・話題、会社とその製品・サービス・機能・子会社
- 迷う場合は出さない

# 出力のルール
- tag には「候補タグ一覧」にある文字列を1字も変えずにそのまま書く。一覧にないタグ名を作ってはいけない
- 対象タグ自身は出さない
- reason は「何と何が、同じものの別表記か」を日本語で1文で書く。タグ名から分かる事実だけを書く
- reason に「〜の可能性がある」「〜することがある」「〜と思われる」などの推測を書いてはいけない。推測が必要なら、そのタグは出さない
- confidence は 0〜1 の自己申告の確からしさ
- 該当がなければ matches を空の配列にする
